# Empire MakeTool

Empire MakeTool is the build tool fork integrated into Empire Game Engine.
It is based on Xmake 3.1.2; upstream notices and license terms are retained in this directory.

- Native kernel: `Make.Kernel/`
- Lua runtime: `Make.Runtime/`
- Build and packaging scripts: `Make.Scripts/`
- Tests: `Empire.Runtime/Runtime.Tests/Tools.Make/`

The executable is named `MakeTool`. Internal Xmake-compatible Lua APIs and configuration filenames are retained during the fork transition.
