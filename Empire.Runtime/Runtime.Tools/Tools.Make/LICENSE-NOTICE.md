# Tools.Make: уведомление о лицензии

Эта папка содержит код проекта **xmake 3.1.2** (https://xmake.io/), (c) The Xmake Open Source Community,
распространяемый по лицензии **Apache License 2.0**. Он переименован и перенесён под архитектуру Empire Game Engine
(`core` -> `Make.Kernel`, `xmake` -> `Make.Runtime`, `scripts` -> `Make.Scripts`, `tests` -> `Make.Tests`,
исполняемый файл `xmake` -> `build`), код при этом изменён.

Что нужно сохранять при распространении (Apache 2.0, раздел 4):
- файлы `LICENSE.md` и `NOTICE.md` из этой папки;
- заметки об авторских правах и лицензии в исходных файлах;
- пометку о том, что файлы изменены (эта заметка).

Остальной код Empire Game Engine этой лицензии не подчиняется.
